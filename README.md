# Dulce & Café — menú

Archivos: index.html (menú), data.json (productos), img/ (logo), netlify/functions/save.js (guardado con código), netlify.toml.

En Netlify (Site configuration → Environment variables) crea:
- EDIT_CODE: tu código secreto (8+ caracteres)
- GITHUB_TOKEN: token de GitHub con permiso Contents: Read and write solo para este repositorio
- GITHUB_REPO: usuario/nombre-del-repositorio
- GITHUB_BRANCH: main (opcional)

Para entrar a editar: en la portada, mantén presionado el logo 5 segundos.
